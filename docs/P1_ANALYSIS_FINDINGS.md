# P1 真实数据描述性发现

由真实执行证据生成；金额单位 BRL；比率为观察期描述，不作因果推断。
范围：2016-09-15–2018-08-29有效购买订单；地区、类目都采用同一范围。以下为P1描述性统计，不是P3经营诊断或因果报告。

1. 有效订单96,478单、唯一购买用户93,358人；商品成交额BRL 13,221,498.11，运费BRL 2,198,275.64，平均订单商品金额BRL 137.04。这些是历史样本的商品金额，不是财务确认收入。证据：mart.kpi_overview。

2. 观察期内至少两单的用户2,801人，复购率3.0003%。分母93,358人，使用customer_unique_id；不同用户观察时长不等，不能将该值解释为长期留存上限。证据：mart.repurchase_summary及repurchase_distribution。

3. 商品金额排名第一的葡语类目为beleza_saude，金额BRL 1,233,131.72，占9.3267%；涵盖8,647个订单。类目订单可能重叠，不把类目订单数相加作为总订单。证据：mart.category_ranking。

4. 按订单客户州归属，SP商品金额最高，为BRL 5,067,633.16，占38.3287%，订单40,501单。描述的是样本分布，不代表市场份额或用户因果偏好。证据：mart.region_sales。

5. 具有效配送日期的96,470单平均交付12.56天；按实际送达日超过预计日定义，96,470单中的逾期率为6.7731%。缺实际送达的8笔有效订单未进入分母。证据：mart.kpi_overview及quality_checks。

6. 有评价的有效订单95,832单，先按订单平均再等权计算，均分4.16。评分分布取每订单最新评价；多评价订单不会获得额外订单权重。证据：mart.order_review_agg及review_distribution。

7. 2017-01 cohort观测首购用户717人，次月回购活跃用户2人，留存0.2789%。所有2018-08目标月尚不可完整观察，矩阵标NA。不能将NA解读为0%回购。证据：mart.cohort_retention及cohort_matrix.csv。

8. RFM采用2018-08-30为基准日；Frequency分位边界为[1, 1, 1, 1]，反映一次购买用户较多，无法形成等人数的五档。相同购买次数同分，未用ID将相同频次强拆。各层人数、占比和金额贡献见P1验收报告及mart.rfm_segments。

SQL源：sql/20_mart.sql、sql/30_customer.sql；独立复核：src/retailscope/p1_validation.py。所有结果CSV/JSON位于reports/p1。未声称增长改善、营销效果或因果关系。
