# 核心指标口径：必须与 SQL、界面、报告保持一致

## 默认范围
- 默认主分析使用 `order_status = 'delivered'` 且有有效 `order_purchase_timestamp` 的订单。订单状态看板另行展示全状态订单。
- `price` 是订单商品行金额，不含运费；货币单位 BRL。数据中没有实际成本、退款全貌和利润，**不能声称净利润或真实净营收**。
- 选择明确的日期边界 `[start_date, end_date)`。展示期间必须提示历史数据的时间范围。

| 指标 | 粒度 / 公式 / 注意事项 |
|---|---|
| 商品成交额（商品金额代理） | `SUM(order_items.price)`，仅关联符合口径的订单；非支付金额，非营业利润 |
| 运费 | `SUM(order_items.freight_value)`，独立于商品金额 |
| 支付金额 | 按订单预聚合 `SUM(payment_value)`；单笔订单可以有多条支付记录，不能直接和商品明细多对多 JOIN |
| 完成订单数 | `COUNT(DISTINCT order_id)`，默认 `delivered` |
| 购买用户数 | `COUNT(DISTINCT customer_unique_id)`，不是 `customer_id` |
| 平均订单商品金额 | 完成订单商品金额 / 完成订单数；非含运费的支付客单价 |
| 复购率 | 观察期内完成订单数≥2 的跨订单唯一用户数 / 观察期内至少完成一单的用户数；注明观察期限制 |
| RFM | Recency：用户末单距离数据快照日的天数；Frequency：完成订单数；Monetary：已完成订单商品金额之和。快照日设为 `max(delivered purchase date)+1 day`；分箱并说明阈值 |
| 月度同期群留存 | 基于用户第一个合格购买月份；留存月 N 的人数 / 该 cohort 的用户数；只使用已有完整观察月份，尚未观察到的月填 NULL / 不显示 |
| 逾期配送率 | 已送达且有实际/预计送达日的订单中，实际送达日>预计日期的比例；异常时间戳单独标记 |
| 平均交付天数 | 已送达订单 `delivered_customer_date - purchase_timestamp` 的平均值；不适用订单为 NULL |
| 评价均分 | 先把 reviews 按订单级聚合，再取订单级评价分数的均值；对多评价订单写明处理策略 |
| 取消率 | 状态为 canceled 的订单数 / 全部订单数；不混入“完成订单”的交易指标 |

## 高风险口径陷阱（需附测试）
1. `customer_id` 可能每笔订单变化；跨订单识别用 `customer_unique_id`。
2. `order_items`、`payments`、`reviews` 对 `orders` 为一对多；必须各自聚合成一单一行再关联，禁止行数膨胀。
3. `geolocation` 同一邮编前缀多条记录；不得直接 JOIN 原始明细求销售额。
4. 2016 年开头和 2018 年结尾可能只有部分月份；环比/同比的可比性需披露，样本外月份不参与统计。
5. 缺失退款、成本、渠道曝光、点击数据；不计算利润、点击转化率或 ROI。
6. 商品销量不等于订单量；一个订单可能有多个商品行。
7. 对检测结果不能写“配送导致差评”，只能写“逾期与低评分存在关联，不能证明因果”。

## P1 固定实现口径（2026-11-13）

- 有效订单：`delivered` 且购买时间有效；一行一个订单。取消/其他状态只进入全状态分布及质量检查。有效订单即使缺商品/支付仍保留在订单数与用户数中，分别标记 `has_items`/`has_payment`；缺商品金额为 NULL，汇总仅统计已知明细，汇总展示时空和为 0，不将缺失等同于真实免费订单。不以缺支付为由删除商品成交额。
- 商品成交额、运费、支付金额均为 BRL，采用 `NUMERIC(18,2)`；Pandas 转整数分后独立复算。客单价=有效订单商品成交额/有效订单数。状态分布覆盖全部订单。类目/地区贡献分母为同范围有效订单商品成交额；类目订单数跨类目不具可加性。
- 时间采用源数据无时区的购买时间，不擅自转换时区。所有日期筛选用左闭右开区间；月度表保留首尾不完整月份并带标记，不直接用于完整月增长比较。
- 地区归属采用该订单 `customer_id` 对应州，不能从唯一用户维表取一个固定州。商品未提供类目显示 `__unknown__`，葡语类目无英文翻译时保留葡语；不丢弃这些交易。
- 邮编统一为五位文本；地理源先整行去重，再按邮编聚合有效全球经纬度的中位数。每邮编一行，地理缺失时维表地理外键为 NULL；保留原邮编。坐标仅为邮编代理位置，不用于精确地址判断。
- 配送天数为 `(实际送达时间-购买时间)` 的秒数/86400；仅有效订单且两者存在、实际送达不早于购买时纳入。逾期采用实际送达日>预计送达日，同日不算迟到；日期异常/缺失不计入配送和逾期分母，单独列出数量。配送异常不排除其真实交易金额。
- 评价按订单先聚合所有源评价（评分必须 1–5）；订单评价均分为订单内均分，再对有评价的有效订单等权平均。分布使用每订单最后回答时间、创建时间、review_id、评分排序确定的最新评分，一订单至多一次；全部原评价记录保留在 core，review_id 不作唯一键。
- RFM 使用所有有效订单，用户键为 `customer_unique_id`。基准日=最后有效购买日+1日，具体日期从 SQL 运行结果写入报告；Recency 按日差，Frequency 按订单数，Monetary 按商品金额。缺商品用户金额保持 NULL，不进行金额评分；正常用户评分基于离散 20/40/60/80% 分位点，相同值同分，不使用按 ID 强拆的 NTILE。R 越小分越高，F/M 越大分越高；重复边界允许空评分档。
- RFM 分组按顺序互斥覆盖：数据待核对（M 缺失）；核心价值（R/F/M 均≥4）；活跃复购（R≥4 且 F≥4）；近期用户（R≥4）；高价值待唤回（R≤2 且 M≥4）；沉睡用户（R≤2）；其他用户。名称只是规则标签，不等同于经实验验证的营销效果。分组用户占比/金额贡献以有效购买用户总数/总商品成交额为分母。
- Cohort 为数据中首次有效购买月份。用户同月多单去重。观察终点保守取最后有效购买所在月份的月初（exclusive），排除末尾未完整月份；最早有效购买月若不是从月初开始，也标为不完整目标月。只有完整目标月的活跃人数/留存率可计算，观察外为 NULL，已观察无复购才为 0。所有 cohort 保留（包括末尾 cohort），生成相同月龄列的长表和矩阵；首月 cohort 获客可能左截断，明确标记。
- 同期群留存=当月有有效购买的 cohort 用户数/cohort 首购用户数，是回购活跃留存，允许中途未买后续返回；不是连续订阅留存。最近 cohort 月龄0不可观察时也为 NULL；新增用户数仍为该月观测首购人数。整体复购分布使用全有效订单历史，各用户观察时长不同，不作因果推断。
- 无效时间/数值文本导致构建失败并回滚，不静默转零；无商品、无支付、缺关联、负金额、异常配送、缺翻译/地理覆盖分别报告。原始数据与 P0 报告保持不变。
