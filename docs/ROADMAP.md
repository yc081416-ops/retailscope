# RetailScope 实习作品交付路线

| 阶段 | 核心工作 | 不可跳过的门槛 |
| --- | --- | --- |
| P0 | 9 CSV 契约、质量报告、PostgreSQL 16 原始入库 | 9 表真实行数与 CSV 一致；重跑行数不变；缺失文件不伪造 |
| P1 | core/mart 分层、经营指标 SQL、RFM、cohort | 一单一行；金额对账；customer_unique_id 复购；cohort 观察窗正确 |
| P2 | Streamlit 6 页、筛选联动、Plotly 导出 | 每页真实 SQL 数据；时间/地区筛选一致；空数据不崩溃 |
| P3 | 规则诊断、≥5 项可复核发现、业务建议 | 每项附 SQL、样本量、指标口径和限制；不声称因果 |
| P4 | 性能、测试、部署说明、演示视频、简历 | 可在新环境复现；3 分钟讲解；没有虚构的业务改善效果 |

**开发顺序固定：只有项目一 P0–P4 完成，才重新考虑项目二。**

对实习的建议：P1 完成且能展示真实 SQL 后可以开始投递，不必等全部页面完成。最终简历只能写自己已实现并验证的能力，不得写虚构的 ROI、利润或业务增长百分比。
